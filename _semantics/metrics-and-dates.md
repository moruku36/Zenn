# メトリクス・計測ソース・日付定義書

> 優先順位: この辞書と一次計測ファイル(請求画面、対象リポジトリの baseline.json や CIログ等)が食い違った場合は、一次計測ファイルを常に上位の正とする。

## 1. 引用時に必ず添えるもの
- 計測日(または確認日)
- 出典(請求画面、対象リポジトリのファイルとコミット、公式ページのURL)
- 環境(該当する場合: OS、バージョン、リージョン、GPU)
- 区分: 観測 / 試算 / 申告 / 公開価格

添えられない項目は「未確認」と書く。

## 2. 費用・時間の扱い

| 数値の種類 | 上位ソース | 注意 |
| --- | --- | --- |
| 契約料金の配賦額 | 請求・契約の原本と、記事内の計算式 | 日割り・配賦は計算結果であり、実際の請求額ではない |
| 為替レート | 記事で置いた仮定値 | 実際の決済レートとは別。仮定であることを書く |
| 人手費用の見積 | 記事で置いた仮の単価 | 相場調査ではない。仮定であることを書く |
| 本人申告の金額 | 申告として書く | 請求履歴の監査結果と書かない |
| 前払い(入金)額 | 入金記録 | 消費額ではない。実際の消費額は確認前は「未確認」 |
| RunPod の実測・課金 | `moruku36/qwen-runpod-operations` の試行レポートと baseline.json | 履歴スナップショット。引用時に日付を添える |

## 3. 日付と期間のルール
- 暦上の期間(「5日間」のような作業期間)と、実測された作業時間・GPU稼働時間を混同して合算・分解しない。
- 日付つきの値は、その日付の観測として書く。現在の値として書く場合は一次記録を再確認する。
- 丸めや「約」を使う場合は、元の値と計算式を同じ節に残す。
