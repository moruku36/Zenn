# 記事執筆・検証記載の規律

対象: Zenn記事、README、DEV記事、振り返りレポートの執筆・更新。起動時には自動ロードされず、CLAUDE.md のトリガー表に当たったときに Read する。

1. `_semantics/terminology-and-roles.md` と `_semantics/metrics-and-dates.md` を先に読む。
2. 書く数値・ステータスの一次ソース(請求原本、対象リポジトリの記録、公式ページ)を開いて照合する。辞書と食い違えば一次ソースを正とする。
3. 数値と検証結果には確認環境(バージョン、コミットハッシュ、確認日)を添える。
4. 確認していない事項は「未確認」、解釈は「推測」と書く。実行していない検証を「完了」「検証済み」と書かない。
5. 自分(AI)の関与範囲は、実際に行った作業だけを書く。
6. 他リポジトリの検証フェーズを引用する場合は、そのリポジトリの辞書の表現に合わせ、確認日を添える。
7. 公開記事(`published: true`)の修正は、変更内容を本人に確認してから行う。

書いたあとに、各数値の出典・日付・環境と、公開ステータスの表記を確認する。
